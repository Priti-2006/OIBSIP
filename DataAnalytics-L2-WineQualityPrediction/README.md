**Task:** Level 2 - Task 2 (Wine Quality Prediction)

## Objective
Train and compare multiple classification models to predict 
the quality of wine based on its physicochemical properties.

## Tools Used
- Python 3.11
- Pandas, NumPy
- Scikit-learn (Random Forest, SGD, SVM)
- Matplotlib, Seaborn
- Jupyter Notebook (VS Code)

## Dataset
Red Wine Quality Dataset from Kaggle (UCI)

## Steps Performed
1. Data Inspection & EDA
2. Feature Distribution Analysis
3. Correlation Heatmap
4. Feature Engineering (Quality Binning)
5. Data Standardization
6. Train/Test Split
7. Random Forest Classifier
8. SGD Classifier
9. SVM Classifier
10. Model Evaluation & Comparison
11. Feature Importance Chart

## Key Insights
- Alcohol content is the strongest predictor of wine quality
- Random Forest performed best among all 3 models
- Class imbalance exists — Medium quality wines dominate
