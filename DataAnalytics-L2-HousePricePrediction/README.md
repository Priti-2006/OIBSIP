**Task:** Level 2 - Task 1 (House Price Prediction)

## Objective
Build and evaluate a linear regression model that predicts 
house prices based on features such as area, quality, 
number of rooms, and age.

## Tools Used
- Python 3.11
- Pandas, NumPy
- Scikit-learn (Linear Regression, Ridge Regression)
- Matplotlib, Seaborn
- Jupyter Notebook (VS Code)

## Dataset
House Prices Advanced Regression Dataset from Kaggle

## Steps Performed
1. Exploratory Data Analysis
2. Feature Selection (Top correlated features)
3. Data Preprocessing (Missing values, Label Encoding)
4. Train/Test Split (80/20)
5. Linear Regression Model Training
6. Ridge Regression Model Training (Bonus)
7. Model Evaluation (MAE, RMSE, R² Score)
8. Actual vs Predicted Plot
9. Residual Plot
10. Feature Importance/Coefficients

## Key Insights
- Overall Quality and Living Area are strongest predictors
- Newer homes command higher prices
- Ridge Regression performs similarly to Linear Regression
