# Google Play Store Analysis

## Oasis Infobyte Data Analytics Internship
**Name:** Priti Ranjit
**Track:** Data Analytics
**Task:** Level 2 - Task 4 (Google Play Store Analysis)

## Objective
Perform comprehensive data analysis of the Google Play Store 
ecosystem — cleaning messy real-world data, exploring app 
categories, analysing ratings and pricing trends, and 
conducting sentiment analysis on user reviews.

## Tools Used
- Python 3.11
- Pandas, NumPy
- TextBlob (Sentiment Analysis)
- Matplotlib, Seaborn
- Jupyter Notebook (VS Code)

## Dataset
Google Play Store Apps Dataset from Kaggle
- googleplaystore.csv
- googleplaystore_user_reviews.csv

## Steps Performed
1. Data Cleaning (fix data types, handle nulls, duplicates)
2. Category Analysis
3. Ratings Analysis
4. Size vs Installs Analysis
5. Pricing Analysis (Free vs Paid)
6. Revenue Estimation by Category
7. Sentiment Analysis on User Reviews
8. Sentiment by Category

## Key Insights
- Family and Game are most saturated categories
- 93% of apps are free
- Average app rating is around 4.1
- Positive sentiment dominates user reviews
- App size has weak correlation with installs
